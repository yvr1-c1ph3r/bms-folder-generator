# beatoraja カスタムフォルダ作成ツール

難易度表・BPM・BP の条件を1画面で選び、掛け合わせたフォルダを beatoraja の `folder/default.json` に生成・追記するツールです。生成済みのフォルダを一覧して個別に削除することもできます。Python の標準ライブラリだけで動きます。

## 起動のしかた

`beatoraja_folder_maker.exe` をダブルクリックします。インストールは不要です。好きな場所に置いて構いません（beatoraja のフォルダの中でなくても動きます）。

ウイルス対策ソフトが警告を出すことがあります。Python製のexeによくある誤検知です。気になる場合は `beatoraja_folder_maker.py` を Python 3.9 以降で直接動かしてください。中身は同じです。

```
python beatoraja_folder_maker.py
```

## 画面の構成

タブは2つです。

- **フォルダを作る** … 上から順に「1. 難易度表」「2. BPM」「3. BP」「4. 生成」。使う段だけチェックを入れます
- **生成したフォルダ** … `default.json` にある現在のフォルダ一覧。右の「削除」で1件ずつ消せます

上部のファイル指定は両方のタブで共通です。

## できあがる場所

作ったフォルダは、beatoraja の選曲画面の一番上の階層にある **`カスタムフォルダ`** の中に入ります。

```
カスタムフォルダ              ← 一番上の階層。無ければ自動で作ります
  Satellite（BP別）           ← 作ったフォルダ（名前は自由）
    BP0
    BP1〜5
    BP6〜10
    未プレイ
  Satellite（BPM別）          ← 2本目以降も同じ場所に並びます
    低速 〜100
    中速 101〜160
    高速 161〜300
    光速 301〜
```

`カスタムフォルダ` は `default.json` の先頭に置きます。すでにある場合はそのまま使い、中身に足します。もとから入っている `MY BEST` などのフォルダには手を触れません。

## 作る手順

1. 画面上部で beatoraja のフォルダを選びます。`folder/default.json` は自動で補われます
2. 「1. 難易度表」で表を選びます（Ctrl・Shift で複数選択）。使わないならチェックを外します
3. 「2. BPM」「3. BP」も同じように、使う段だけチェックを入れて区間を決めます
4. 「4. 生成」の「フォルダ名」に好きな名前を入れます。空のままでも構いません
5. **プレビュー（書き込まない）** を押し、できる中身とファイルサイズをログで確認します
6. 問題なければ **生成して書き込む** を押します
7. beatoraja を再起動します

## 条件の組み合わせ方

**難易度表は「その表に入っている譜面だけに絞る」条件として働きます。** レベルでは分けません。フォルダの中身になるのは BPM と BP の区切りです。

| 選んだ条件 | できる中身 |
|---|---|
| 難易度表 + BP | `BP0` `BP1〜5` `BP6〜10` … `未プレイ` |
| 難易度表 + BPM | `低速 〜100` `中速 101〜160` `高速 161〜300` `光速 301〜` |
| 難易度表 + BPM + BP | `低速 〜100 / BP0` `低速 〜100 / BP1〜5` … |
| BPM のみ | `低速 〜100` `中速 101〜160` … |
| BP のみ | `BP0` `BP1〜5` … `未プレイ` |
| BPM + BP | `低速 〜100 / BP0` … |
| 難易度表のみ | `sl0` `sl1` … `sl12`（この場合だけレベルで分けます） |

たとえば Satellite と BP を選ぶと、Satellite に入っている譜面すべてを対象に、レベルを問わず BP だけで振り分けます。sl0 の譜面も sl12 の譜面も、BP0 なら同じ `BP0` フォルダに入ります。

難易度表を2つ以上選んだ場合は、両方の譜面をまとめた1つの対象になります。難易度表だけを選んだ場合に限り、区別のため表名が頭に付きます（`Satellite sl0`）。

## フォルダ名

「4. 生成」のテキストボックスで決めます。空のままにすると、下に案内が出ている自動の名前になります。

| 条件例 | 自動の名前 |
|---|---|
| Satellite + BP | `Satellite（BP別）` |
| Satellite + BPM | `Satellite（BPM別）` |
| Satellite + BPM + BP | `Satellite（BPM・BP別）` |
| Satellite + Stella + BP | `Satellite・Stella（BP別）` |
| BPM のみ | `BPM別` |
| BP のみ | `BP別` |
| BPM + BP | `BPM・BP別` |

`カスタムフォルダ` の中に同じ名前のフォルダが既にある場合は、そのフォルダだけが置き換わります。作り分けたいときは名前を変えてください。

## 各段でできること

### 1. 難易度表

初期状態で4つの表に対応しています。

| 表 | header |
|---|---|
| Satellite（sl0〜sl12） | `https://stellabms.xyz/sl/header.json` |
| Stella（st0〜st12） | `https://stellabms.xyz/st/header.json` |
| 発狂BMS難易度表（▼0-〜▼24） | `https://rattoto10.github.io/second_table/insane_header.json` |
| 第2通常難易度表（▽1〜▽12+） | `https://bmsnormal2.syuriken.jp/js/header.json` |

他の表を足したいときは、下の入力欄に表のページURL（例 `https://stellabms.xyz/sl/table.html`）か `header.json` のURLを入れて「追加」を押します。ページURLなら `<meta name="bmstable">` からヘッダを自動で探します。BMS Table 形式（header + data の2ファイル構成）の表であれば、たいていそのまま読めます。

一度取得した表はアプリを終了するまで再利用します。表が更新されたときは、アプリを再起動してから作り直してください。

### 2. BPM

`低速 〜100` `中速 101〜160` `高速 161〜300` `光速 301〜` が初期値です。名前・下限・上限を自由に足したり消したり、`↑` `↓` で並べ替えたりできます。生成されるSQLは次の形です。

```
song.minbpm >= 101 AND song.maxbpm <= 160
```

BMSの最低BPMと最高BPMの両方で挟むため、途中でBPMが大きく変わる譜面はどの区間にも入りません。ソフランを含めたいなら上限だけ、または下限だけの条件にしてください。

### 3. BP

自己ベストの最小BAD+POOR（`score.minbp`）で絞ります。初期値は `BP0` `BP1〜5` `BP6〜10` `BP11〜20` `BP21〜50` `BP51〜` です。

```
score.minbp IS NOT NULL AND score.minbp >= 1 AND score.minbp <= 5
```

未プレイの譜面は `minbp` が空なので自動的に除かれます。「未プレイ」にチェックを入れると `score.clear IS NULL` のフォルダが別に付きます。

参照するのは `player/<プレイヤー名>/score.db` です。プレイヤーを切り替えると中身も変わります。

## 生成したフォルダタブ

「読み込む / 再読込」で現在の `default.json` を読み、次の順で一覧します。

1. `カスタムフォルダ`（太字）と、その中に作ったフォルダ（1段下げて表示）
2. `── カスタムフォルダ 以外のトップレベル ──` 以下に、`MY BEST` などもとから入っているフォルダ

中身の欄には、子フォルダの数と末端フォルダの数、またはSQLの先頭が出ます。

右の「削除」を押すと確認のうえでその1件を消し、`default.json` を書き直します。`カスタムフォルダ` の行で削除すると、中身ごとまとめて消えます。確認ダイアログに件数が出ます。

書き換える前に必ずバックアップを作ります。削除後も beatoraja の再起動が必要です。

## 難易度表フォルダのしくみと制約

beatoraja は難易度表を `table/` フォルダの `.bmt`（gzip圧縮したJSON）に保存します。SQLがアクセスできるデータベースには難易度表のレベルが入っていないため、`sl5` のような条件をSQLに直接書くことはできません。

そこで本ツールは、難易度表の配布JSONから譜面の `md5` を取り出し、次の形に展開します。

```
(song.md5 IN ('280b39eb...','1d5ae542...', ... ))
```

このため次の点に注意してください。

- **持っていない譜面は出てきません。** 難易度表フォルダのように「未所持の曲名だけ表示される」動きにはなりません
- **md5が変わると外れます。** 表の更新で差分が差し替わった場合、作り直しが必要です
- **表側のデータがmd5を持たない譜面は sha256 で照合します。** どちらも無い譜面は落ちます
- **中身の件数だけファイルが大きくなります。** 中の1件ずつが独立したSQLを持つため、表の譜面すべてのmd5一覧が件数ぶん複製されます。BP7区間なら7回、BPM4区間 × BP7区間なら28回です。実際のサイズはプレビューで確認できます。3MBを超える場合は書き込み前に確認を出します

## 気をつける点

- 読み込まれるのは `folder/default.json` だけです。`folder/my.json` のような別名のファイルは beatoraja が読みません（本体側でパスが固定されています）
- JSONで使えるキーは `name` `sql` `folder` `showall` `rcourse` の5つだけです。1か所でも別のキーがあると、`default.json` 全体が読み込まれなくなります。本ツールは書き込み前に検査します
- `songinfo.db` を有効にしている場合、beatoraja のSQLは `information` テーブルと内部結合します。`songinfo.db` にデータが無い譜面は作ったフォルダに出てきません
- 手書きで末尾カンマなどを入れた `default.json` は、Pythonの標準JSONでは読めないことがあります。その場合はエラーを出して書き込みを中止します。既存ファイルを退避してから実行してください
- 以前のバージョンで作った `オリジナルフォルダ` が残っている場合は、「生成したフォルダ」タブから削除できます
- バックアップは `default.json.20260824_130512.bak` のように同じフォルダへ溜まります。不要になったら手で消してください

## 動作確認の内容

beatoraja 本体（`SQLiteSongDatabaseAccessor#getSongDatas`）と同じ形のSQLを組み、同じスキーマの `songdata.db` / `score.db` / `scorelog.db` / `songreview.db` を作って、生成されるWHERE句が意図した譜面だけを返すか検証しています。

- 条件の組み合わせ10通り（表+BP／表+BPM／表+BPM+BP／表のみ／表2つのみ／表2つ+BP／BPMのみ／BPのみ／未選択／フォルダ名を指定）で、入れ子が作られないこと、キーの検査が通ること
- 難易度表 + BP、難易度表 + BPM で、表に入っていない譜面が混ざらず、各区間が期待した譜面だけを返すこと
- フォルダ名の自動生成が、条件の組み合わせごとに想定した文字列になること
- `カスタムフォルダ` が無い状態では先頭に作られ、既にある状態では中身に足されること。同名で作り直すとその1本だけが置き換わり、他のトップレベルフォルダが動かないこと
- `カスタムフォルダ` と同名でSQLを直接持つフォルダがある場合に、書き込まずエラーを出すこと
- 中の1本だけの削除と、`カスタムフォルダ` ごとの削除が、どちらも正しく書き戻されること
- BPM4区間・BP6区間・未プレイ・md5照合・sha256照合・md5を5000件並べた場合も期待どおりであること
- 既存ファイルの読み込み、同名フォルダの置き換え、削除、バックアップ生成が動くこと
