# beatoraja カスタムフォルダ作成ツール

難易度表・BPM・BP・クリアランプ・DJ LEVEL の条件を1画面で選び、掛け合わせたフォルダを beatoraja の `folder/default.json` に生成・追記するツールです。生成済みのフォルダを一覧して個別に削除することもできます。インストールは不要です。

## 起動のしかた

`beatoraja_folder_maker.exe` をダブルクリックします。好きな場所に置いて構いません（beatoraja のフォルダの中でなくても動きます）。

ウイルス対策ソフトが警告を出すことがあります。Python製のexeによくある誤検知です。消されてしまう場合は、除外設定に入れてください。

## ファイル

| ファイル | 役割 |
|---|---|
| `beatoraja_folder_maker.exe` | 本体。これをダブルクリック |
| `README.md` | この説明 |
| `difficulty_tables.json` | 取り込んだ難易度表の保存先。初回の取得時に自動で作られます |

`difficulty_tables.json` は exe と同じフォルダに作ります。そこに書き込めない場合（Program Files に置いたときなど）は `%LOCALAPPDATA%\beatoraja_folder_maker\` に作ります。実際の場所は起動直後のログに出ます。

## 画面の構成

タブは2つです。

- **フォルダを作る** … 上から順に「1. 難易度表」「2. BPM」「3. BP」「4. LAMP」「5. SCORE」「6. 生成」。使う段だけチェックを入れます
- **生成したフォルダ** … `default.json` にある現在のフォルダ一覧。右の「削除」で1件ずつ消せます

上部のフォルダ指定は両方のタブで共通です。「folderを選ぶ…」で beatoraja本体（`beatoraja.exe` や `beatoraja.bat`）と同じ場所にある `folder` フォルダを指定します。beatoraja のフォルダ自体を選んでも構いません。`default.json` を直接指定することもできます。

## できあがる場所

作ったフォルダは、beatoraja の選曲画面の一番上の階層にある **`カスタムフォルダ`** の中に入ります。

```
カスタムフォルダ              ← 一番上の階層。無ければ自動で作ります
  Satellite（BP別）           ← 作ったフォルダ（名前は自由）
    BP≦10
    11≦BP≦20
    21≦BP≦30
    未プレイ
  Satellite（BPM別）          ← 2本目以降も同じ場所に並びます
    低速 - 100
    中速 101 - 160
    高速 161 - 300
    光速 301 -
```

`カスタムフォルダ` は `default.json` の先頭に置きます。すでにある場合はそのまま使い、中身に足します。もとから入っている `MY BEST` などのフォルダには手を触れません。

## 作る手順

1. 画面上部で、beatoraja本体と同じ場所にある **folder** フォルダを選びます。中の `default.json` が対象です
2. 「1. 難易度表」で表を選びます（Ctrl・Shift で複数選択）。使わないならチェックを外します
3. 「2. BPM」「3. BP」「4. LAMP」「5. SCORE」も同じように、使う段だけチェックを入れて区切りを決めます
4. 「6. 生成」の「フォルダ名」に好きな名前を入れます。空のままでも構いません
5. **プレビュー（書き込まない）** を押し、できる中身とファイルサイズをログで確認します
6. 問題なければ **生成して書き込む** を押します
7. beatoraja を再起動します

名前・下限・上限を並べる欄では、**名前を空にして「追加」を押すと、下限・上限から自動で名前を付けます**（`11≦BP≦20` `101 - 160` など）。

## 条件の組み合わせ方

**難易度表は「その表に入っている譜面だけに絞る」条件として働きます。** レベルでは分けません。フォルダの中身になるのは BPM・BP・LAMP・SCORE の区切りで、**BPM → BP → LAMP → SCORE の順**に名前がつながります。

| 選んだ条件 | できる中身 |
|---|---|
| 難易度表 + BP | `BP≦10` `11≦BP≦20` … `未プレイ` |
| 難易度表 + BPM | `低速 - 100` `中速 101 - 160` `高速 161 - 300` `光速 301 -` `ソフラン` |
| 難易度表 + LAMP | `FAILED` `ASSIST` `EASY` `CLEAR` `HARD` `EX-HARD` `FULLCOMBO` |
| 難易度表 + SCORE | `DJ LEVEL - B` `DJ LEVEL A` `DJ LEVEL AA` `DJ LEVEL AAA` |
| 難易度表 + LAMP + SCORE | `HARD / DJ LEVEL AA` `HARD / DJ LEVEL AAA` … |
| 難易度表 + BPM + BP + LAMP + SCORE | `低速 - 100 / BP≦10 / FAILED / DJ LEVEL - B` … |
| BPM のみ | `低速 - 100` `中速 101 - 160` … |
| BP のみ | `BP≦10` `11≦BP≦20` … `未プレイ` |
| LAMP のみ | `FAILED` … `FULLCOMBO` |
| SCORE のみ | `DJ LEVEL - B` … `DJ LEVEL AAA` |
| 難易度表のみ | `sl0` `sl1` … `sl12`（この場合だけレベルで分けます） |

BPの「未プレイ」と LAMP・SCORE を同時に選んだ場合、その組み合わせは作りません。未プレイの譜面にクリアランプもDJ LEVELも付かないため、必ず空になるからです。

たとえば Satellite と BP を選ぶと、Satellite に入っている譜面すべてを対象に、レベルを問わず BP だけで振り分けます。sl0 の譜面も sl12 の譜面も、BPが5なら同じ `BP≦10` フォルダに入ります。

難易度表を2つ以上選んだ場合は、両方の譜面をまとめた1つの対象になります。難易度表だけを選んだ場合に限り、区別のため表名が頭に付きます（`Satellite sl0`）。

### 最下層を難易度レベルにする

「1. 難易度表」の一番下にある **最下層を難易度レベルにする** にチェックを入れると、組み合わせのフォルダの中に、レベルごとのフォルダを作ります。

```
カスタムフォルダ
  Satellite・発狂BMS難易度表（BPM別）
    低速 - 100
      sl0 ／ sl1 … ／ ★1 ／ ★2 …
    中速 101 - 160
      sl0 ／ sl1 … ／ ★1 ／ ★2 …
```

チェックを外したときは、これまでどおり組み合わせのフォルダが末端になります（表全体が対象）。

レベル名は記号だけです（`sl0` `★1`）。複数の表で同じ表記が重なったときだけ、表名を頭に付けます。

フォルダの数は「組み合わせの数 × レベル数」です。BPM 5区間に Satellite（13）と発狂★（26）を足すと 195 になります。次の「譜面が0件のフォルダを作らない」と一緒に使うと、実際に持っている組み合わせだけが残ります。

### 条件ごとに分けて作るのがおすすめ

複数を同時に選ぶと、組み合わせの数が掛け算になります。初期値のままなら BPM 5行 × BP 6行（5区間＋未プレイ）で **30フォルダ**、LAMP 7行と SCORE 4行まで足すと **700フォルダ**（840通りから未プレイとの組み合わせ140通りを除いた数）が1階層に並びます。

```
カスタムフォルダ
  Satellite（BPM・BP別）
    低速 - 100 / BP≦10
    低速 - 100 / 11≦BP≦20
    …
    ソフラン / 未プレイ        ← 全部で30個
```

選曲画面で目的のフォルダを探しにくくなります。同じことをするなら、**条件ごとに分けて作るほうが使いやすい**です。

1. BPMだけを選んで `Satellite（BPM別）` を作る（5フォルダ）
2. BPだけを選んで `Satellite（BP別）` を作る（6フォルダ）
3. LAMPだけを選んで `Satellite（LAMP別）` を作る（7フォルダ）
4. SCOREだけを選んで `Satellite（SCORE別）` を作る（4フォルダ）

合わせて22フォルダで済み、「今日は中速をやりたい」「BPを減らしたい」「HARDを埋めたい」「AAAを狙いたい」のどこからでも入れます。ファイルも小さくなります。

掛け合わせたいときは、区切りを絞ってから作ってください。たとえばLAMP側を `EASY` と `CLEAR` の2行だけ、SCORE側を `DJ LEVEL AA` の1行だけにすれば、2フォルダで収まります。

## フォルダ名

「6. 生成」のテキストボックスで決めます。空のままにすると、下に案内が出ている自動の名前になります。

| 条件例 | 自動の名前 |
|---|---|
| Satellite + BP | `Satellite（BP別）` |
| Satellite + BPM | `Satellite（BPM別）` |
| Satellite + BPM + BP | `Satellite（BPM・BP別）` |
| Satellite + Stella + BP | `Satellite・Stella（BP別）` |
| Satellite + LAMP | `Satellite（LAMP別）` |
| Satellite + SCORE | `Satellite（SCORE別）` |
| BPM のみ | `BPM別` |
| BP のみ | `BP別` |
| LAMP のみ | `LAMP別` |
| SCORE のみ | `SCORE別` |
| BPM + BP + LAMP + SCORE | `BPM・BP・LAMP・SCORE別` |

`カスタムフォルダ` の中に同じ名前のフォルダが既にある場合は、そのフォルダだけが置き換わります。作り分けたいときは名前を変えてください。

## 譜面が0件のフォルダを作らない

「6. 生成」にあるチェックボックスです。初期状態でオンになっています。

オンのときは、書き込む前に `songdata.db` と `player/<プレイヤー名>/score.db` `scorelog.db` を**読み取り専用**で開き、フォルダごとに当てはまる譜面の数を数えます。0件のフォルダは作りません。中身が全部消えた親フォルダも一緒に消します。

- DBは読み取り専用で開くため、beatoraja のデータを書き換えることはありません
- `score.db` が無いプレイヤーの場合は、すべて未プレイとして数えます
- `songdata.db` が見つからないなど数えられないときは、ログに理由を出して、0件のフォルダもそのまま作ります

右の「プレイヤー」で、どのプレイヤーのスコアで数えるかを選べます。`player` フォルダを探して並べ、`config.json` の `playername` があればそれを最初に選びます。BPやLAMPやSCOREで絞るときは、ここが beatoraja で遊んでいるプレイヤーと合っているか確認してください。

数え上げは組み合わせの数だけSQLを流します。数百件あると数秒かかることがあります。進み具合は画面下の行に出ます。

## 各段でできること

### 1. 難易度表

初期状態で5つの表に対応しています。

| 表 | レベル表記 | header |
|---|---|---|
| Satellite | `sl0`〜`sl12` | `https://stellabms.xyz/sl/header.json` |
| Stella | `st0`〜`st12` | `https://stellabms.xyz/st/header.json` |
| 発狂BMS難易度表（★・GENOCIDE） | `★1`〜`★25` `★???` | `https://miraiscarlet.github.io/bms/table/genocide_insane/header_insane.json` |
| NEW GENERATION 発狂難易度表（▼・第二期） | `▼0-`〜`▼24` `▼?` | `https://rattoto10.github.io/second_table/insane_header.json` |
| 第2通常難易度表（▽） | `▽1`〜`▽12+` | `https://bmsnormal2.syuriken.jp/js/header.json` |

一覧には表の名前と状態（`未取得` または `2417譜面 / 13レベル / 2026-08-24 取得`）が出ます。選ぶと下にURLが出ます。

**表を追加する** … 下の入力欄に表のページURL（例 `https://stellabms.xyz/sl/table.html`）か `header.json` のURLを入れて「追加」を押します。ページURLなら `<meta name="bmstable">` からヘッダを自動で探します。BMS Table 形式（header + data の2ファイル構成）の表であれば、たいていそのまま読めます。

**表を取得する** … 「選択した表を取得 / 更新」を押すと、いま取得して保存します。押さずにフォルダを生成した場合も、その時に取得して保存します。

**取得した表は保存されます。** いちど取得すれば、アプリを閉じても次の起動でそのまま使えます。ネットにつながっていなくてもフォルダを作れます。表が更新されたときは、その表を選んで「選択した表を取得 / 更新」を押すと最新に入れ替わります。

**表を削除する** … 「選択した表を削除」を押すと、一覧から消え、保存してあるデータも消えます。既定の5つの表も削除できます。削除は記録されるので、次に起動しても戻ってきません。同じURLを「追加」すれば復活します。すでに作ったフォルダは削除しても残ります。

### 2. BPM

`低速 - 100` `中速 101 - 160` `高速 161 - 300` `光速 301 -` `ソフラン` が初期値です。名前・下限・上限を自由に足したり消したり、`↑` `↓` で並べ替えたりできます。生成されるSQLは次の形です。

```
song.minbpm >= 101 AND song.maxbpm <= 160
```

譜面の最低BPMと最高BPMの両方で挟みます。そのため BPM 100→200 のようなソフランは、どの固定区間にも入りません。

### ソフラン（BPM変化あり）

上限の右にある **BPM変化あり** にチェックを入れて追加すると、下限・上限を無視して、BPMが変化する譜面だけを集める行になります。

```
song.minbpm != song.maxbpm
```

初期値に `ソフラン` という名前でこの行が入っています。チェックを入れて追加した行は、一覧に `BPM変化あり` と表示されます。下限・上限に数字を入れていても使いません。

判定は最低BPMと最高BPMが違うかどうかです。次の点に注意してください。

- BPM 150→155 のように変化の幅が狭い譜面は、`ソフラン` と `中速 101 - 160` の両方に入ります。どちらの条件も満たすためです
- STOP（譜面停止）だけでBPMが変わらない譜面は入りません。最低BPMと最高BPMが同じためです

### 3. BP

自己ベストの最小BAD+POOR（`score.minbp`）で絞ります。初期値は `BP≦10` `11≦BP≦20` `21≦BP≦30` `31≦BP≦50` `51≦BP` です。

```
score.minbp IS NOT NULL AND score.minbp >= 11 AND score.minbp <= 20
```

未プレイの譜面は `minbp` が空なので自動的に除かれます。「未プレイ」にチェックを入れると `score.clear IS NULL` のフォルダが別に付きます。

参照するのは `player/<プレイヤー名>/score.db` です。プレイヤーを切り替えると中身も変わります。

### 4. LAMP

自己ベストのクリアランプで絞ります。初期値は `FAILED` `ASSIST` `EASY` `CLEAR` `HARD` `EX-HARD` `FULLCOMBO` の7つです。

下限と上限は次から選びます。括弧内は beatoraja が `score.db` に記録している値です。

| 選べる値 | score.clear | 備考 |
|---|---|---|
| `NO PLAY` | 0 | |
| `FAILED` | 1 | |
| `ASSIST` | 2 | ASSIST EASY |
| `L-ASSIST` | 3 | LIGHT ASSIST EASY |
| `EASY` | 4 | |
| `CLEAR` | 5 | NORMAL |
| `HARD` | 6 | |
| `EX-HARD` | 7 | |
| `FULLCOMBO` | 8 | |
| `PERFECT` | 9 | |
| `MAX` | 10 | |

初期値の `ASSIST` は下限 `ASSIST`・上限 `L-ASSIST` で2種類をまとめています。生成されるSQLは次の形です。

```
score.clear = 6
score.clear >= 9 AND score.clear <= 10
```

`PERFECT` と `MAX` は初期値に入れていません。必要なら下限 `PERFECT`・上限 `MAX` で1行足してください。「HARD以上」なら下限 `HARD`・上限 `MAX` です。

未プレイの譜面はどのランプにも入りません。`score.db` に記録がなく、比較の対象にならないためです。`NO PLAY` を選んだ場合に入るのは、記録があって値が0の譜面だけです。未プレイを集めたいときは「3. BP」の「未プレイ」を使ってください。

### 5. SCORE

自己ベストのDJ LEVELで絞ります。初期値は `DJ LEVEL - B` `DJ LEVEL A` `DJ LEVEL AA` `DJ LEVEL AAA` の4つです。

下限と上限は `F` `E` `D` `C` `B` `A` `AA` `AAA` から選びます。`DJ LEVEL A` は下限も上限も `A`、つまり A以上 AA未満という意味です。`DJ LEVEL - B` は下限 `F`・上限 `B` なので、B以下すべて（B C D E F）が入ります。

判定はEXスコア（PGREAT 2点 + GREAT 1点）とノート数から出します。

```
score.notes > 0
AND ((score.epg + score.lpg) * 2 + score.egr + score.lgr) * 9 >= score.notes * 16
```

スコアレートは `EXスコア ÷ (ノート数 × 2)` で、AAA は 8/9（約88.89%）以上、AA は 7/9、A は 6/9、B は 5/9 以上です。AAAちょうどの点数がAAAに入るよう、端の1点でずれない計算にしています。

未プレイの譜面はどのDJ LEVELにも入りません。参照先は BP と同じ `player/<プレイヤー名>/score.db` です。

## 生成したフォルダタブ

「読み込む / 再読込」で現在の `default.json` を読み、次の順で一覧します。

1. `カスタムフォルダ`（太字）と、その中に作ったフォルダ（1段下げて表示）
2. `── カスタムフォルダ 以外のトップレベル ──` 以下に、`MY BEST` などもとから入っているフォルダ

中身の欄には、子フォルダの数と末端フォルダの数、またはSQLの先頭が出ます。

右の「削除」を押すと確認のうえでその1件を消し、`default.json` を書き直します。`カスタムフォルダ` の行で削除すると、中身ごとまとめて消えます。確認ダイアログに件数が出ます。

書き換える前に必ずバックアップを作ります。削除後も beatoraja の再起動が必要です。

## 難易度表フォルダのしくみと制約

beatoraja は難易度表を `table/` フォルダの `.bmt`（gzip圧縮したJSON）に保存します。SQLがアクセスできるデータベースには難易度表のレベルが入っていないため、`sl5` のような条件をSQLに直接書くことはできません。

そこで本ツールは、難易度表の配布JSONから譜面の `md5` を取り出し、次の形に展開します。

```
(song.md5 IN ('280b39eb...','1d5ae542...', ... ))
```

このため次の点に注意してください。

- **持っていない譜面は出てきません。** 難易度表フォルダのように「未所持の曲名だけ表示される」動きにはなりません
- **md5が変わると外れます。** 表の更新で差分が差し替わった場合、作り直しが必要です
- **表側のデータがmd5を持たない譜面は sha256 で照合します。** どちらも無い譜面は落ちます
- **中身の件数だけファイルが大きくなります。** 中の1件ずつが独立したSQLを持つため、表の譜面すべてのmd5一覧が件数ぶん複製されます。BP6区間なら6回、BPM5区間 × BP6区間なら30回です。実際のサイズはプレビューで確認できます。3MBを超える場合は書き込み前に確認を出します

## 気をつける点

- 読み込まれるのは `folder/default.json` だけです。`folder/my.json` のような別名のファイルは beatoraja が読みません（本体側でパスが固定されています）
- JSONで使えるキーは `name` `sql` `folder` `showall` `rcourse` の5つだけです。1か所でも別のキーがあると、`default.json` 全体が読み込まれなくなります。本ツールは書き込み前に検査します
- `songinfo.db` を有効にしている場合、beatoraja のSQLは `information` テーブルと内部結合します。`songinfo.db` にデータが無い譜面は作ったフォルダに出てきません
- 手書きで末尾カンマなどを入れた `default.json` は、Pythonの標準JSONでは読めないことがあります。その場合はエラーを出して書き込みを中止します。既存ファイルを退避してから実行してください
- 以前のバージョンで作った `カスタムフォルダ` が残っている場合は、「生成したフォルダ」タブから削除できます
- バックアップは `default.json.20260824_130512.bak` のように同じフォルダへ溜まります。不要になったら手で消してください
